# StockAI

StockAI is a Python-based investment analysis platform designed to automate
market data collection, technical analysis, investment scoring, and AI-powered
market insights.

## Features

- Historical market data downloader
- SQLite data storage
- Technical indicators
- Investment scoring engine
- AI-generated market summaries
- Streamlit dashboard
- Email and Telegram alerts
